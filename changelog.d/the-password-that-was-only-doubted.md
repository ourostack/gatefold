---
title: The Password That Was Only Doubted
kind: fix
---
When the Cloud let a sign-in lapse, Gatefold quietly signed you in again with the password you gave it. But the Cloud has a nervous habit: now and then it turns away a perfectly good password with the very same words it uses for a wrong one. One such fright and Gatefold threw your password away, and every page you read after that stayed stranded on your phone. Now a single refusal is only a doubt: Gatefold keeps the password, waits a minute, and knocks again. Only a second refusal in a row is taken to mean the password really changed.
