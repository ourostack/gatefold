---
title: The Download That Learned to Say Where
try: Tap a book that lives only in your Cloud and watch it come down to the shelf.
---
A book that wouldn't come down from the Cloud used to fail without a word about why, so nobody could mend it.
Now each download leaves a small note on the way out: where it stopped and the code it got, and never the book's name or yours. And a download link the Cloud has let go stale is asked for afresh on any refusal, not only the few it used to know.
